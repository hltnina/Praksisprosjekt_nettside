# Praksisprosjekt nettside

_I dette faget har vi som prosjekt å etablere en nettside, hvor vi presenterer våres perspektiv gjennom faget IS-302 praksisprosjekt. Vi har laget en prototype for hvordan vi vil presentere vår nettside, for å enkeltgjøre jobben videre gjennom koding. Vi er gruppe på tre jenter som ønsker å nå målene våres innenfor kommunikasjon, koding, gjennomføring av prosjekt og generelt holde en rød tråd gjennom dette faget for å få et godt grunnlag til faget._
